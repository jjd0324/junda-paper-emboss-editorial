# 严格文字模式

图像生成模型适合生成纸材、压痕、光影和抽象布局，但不应被承诺为可靠的中文或小字号排版引擎。下列模式适用于品牌名、引文、数据、日期、活动信息或任何需要逐字一致的内容。

## 分层交付

1. **艺术底图**：生成无可读文字的纸张、浮雕/压凹关系和为标题预留的明确空位。提示词应写明 `NO TEXT ON ART LAYER`，不能以假字或乱码充数。
2. **可编辑文字层**：用 SVG、Figma、Canva、Illustrator 或用户已有排版工具写入用户提供的原文。文字层至少分成标题、可选副标题和微型索引三组。
3. **工艺匹配**：在文字层上加入同向、低对比的高光与阴影或内阴影，让标题看起来是轻击凸或压凹；不要用粗描边、厚阴影或发光。
4. **最终检查**：将文字层置于底图上，检查所有字、数字、标点、换行、边距和裁切安全区。准确性以用户原文为准，不能由模型自动改写。

最终交付必须包含实际可编辑文字层文件，或明确标注“仅交付无字艺术底图，文字层尚未制作”；不能把口头说明当作已完成的准确排版。

## 内置文字层模板

默认 `3:4` 输出可从 [editable-text-overlay-3x4.svg](../assets/editable-text-overlay-3x4.svg) 复制一份作为透明文字层。它保留 `{{TITLE}}`、`{{SUBTITLE}}` 和 `{{INDEX}}` 三个可编辑占位符，以及 108 px 的安全边距；在 Figma、Illustrator 或任意 SVG 编辑器中替换为用户原文后，再叠加到无字艺术底图。

横版 `16:9` Hero 可从 [editable-text-overlay-16x9.svg](../assets/editable-text-overlay-16x9.svg) 开始。它将标题、辅助标题和索引限制在左侧 `8–48%` 的安全区，避开 `signal-path-hero` 默认的右侧路径；如果用户把主视觉改到左边，应镜像或重新排布该文字层，而不是把文字压到路径上。

模板只解决文字精度与安全区，不应替代本次设计的标题角色。若主标题需要跨边缘、穿过压纹或改用不同版式，应在保留原文准确性的前提下调整 SVG 的位置、字号和字重。

## 何时不必启用

只有 1–3 个常见短词、用户明确接受生成式近似、且微型文字不承担事实信息时，可以直接由图像模型生成。文章标题、书名、公众号封面标题默认不适用这一例外。交付时仍需明确它不是逐字排版保证。

## 给用户的说明方式

简洁说明：“底图已生成；标题采用可编辑文字层，保证文案准确。若只需灵感图，可直接使用生成图中的近似文字。”
