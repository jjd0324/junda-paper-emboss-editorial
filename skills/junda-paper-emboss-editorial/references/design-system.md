# 俊达·纸面压纹视觉设计系统

本参考只在实际生成纸面压纹视觉时读取。先选一个版式家族、一个纸面动作和一个工艺主次关系；不要把全部选项塞进同一张图。

## 不可变锚点

1. **纸材优先**：无涂层暖白、冷白或染色纸，能看见细纤维、轻微压纹或自然纸纹；背景不是纯数字色块。
2. **浅工艺优先**：每张选择一个主纸面动作（击凸、压凹、纸缝或轻折），必要时只用一个互补动作辅助。所有起伏都在纸面毫米级以内，用边缘压痕、柔侧光和克制阴影说明，而不是做成厚塑料、雕塑或金属铭牌。
3. **文字参与构图**：标题、图形与留白要共享边界、穿插、借位或比例关系。标题不应像普通海报上后来贴的一行字。
4. **少而准**：一个主隐喻、一个主标题、最多两级辅助信息；局部微文案只承担编辑索引作用。
5. **安静的编辑气质**：有书封、独立杂志或展览印刷品的秩序感，避免模板化居中标题与抢眼特效。

## 版式家族

### 1. 字词纪念碑（monumental word）

让一个短标题、首字母或数字成为画面主体，以浅击凸、压凹或缺口承担视觉重量。副标题与索引退到边缘。适合观点、书封、单主题活动和标题本身就是隐喻的内容。

### 2. 边缘张力（edge tension）

把主标题锚在边缘、角落或跨越折线的位置；主隐喻从另一侧进入画面，二者在留白中形成拉力。适合短、锋利的标题和城市、行动、突破类主题。

### 3. 留白中的凹槽（recessed field）

以大面积纸面留白为主体，让压凹的圆、门、轨迹、折页或文字从中低调出现。微型索引围绕边界排列。适合反思、阅读、时间、安静、关系等主题。

### 4. 版面切分（editorial split）

用一个半圆、竖向压纹、折页或色块把画面划成两个不等区域。标题可跨越分界，击凸元素与压凹元素在两区交换主次。适合双重关系、对照、选择、转折类主题。

## 工艺主次关系

每张只选一种为主，另一种为辅：

- **raised type / recessed symbol**：主标题轻击凸，隐喻图形压凹；适合强调一句话。
- **recessed type / raised path**：标题近同色压凹，路径、线或局部几何轻击凸；适合克制、探索、过程类主题。
- **tone-on-tone relief**：标题和图形保持近同色，以不同高度和同一方向的侧光显形；适合高端、安静、收藏感的封面。

## 纸基与色彩职责

- 先选择纸基，再选 1–2 个印色。纸基不是第三个装饰色，而是承载所有压纹关系的材料。
- 单色时，颜色承担图形、标题和索引，通过密度与纸面受光区分层级。
- 两色时，为每种颜色指定职责，例如“深色承担主隐喻、暖色只标记转折”或“深蓝承载压凹区域、暖白保留标题安全区”。第二色不能只是零散点缀。
- 默认避免综合色渐变；纸面明暗只能来自同一方向的侧光与材料起伏。

## 字体与信息层级

- 主标题从高对比衬线、现代无衬线、压缩体、细长体、几何体或编辑感字体中选一类；只在确有必要时混合第二类。
- 主标题与副标题的大小必须产生显著反差；微型索引应像页码、日期、坐标、编号或短横线，而非另一个标题。
- 中文注意字面呼吸与行距，英文可用字距变化或局部竖排。不要为了“设计感”故意拼错、拆坏用户的正文。

## 配色

- 优先：暖白 + 炭黑、米白 + 深蓝、赭黄 + 黑、森林绿 + 米白、砖红 + 暖灰、午夜蓝 + 柔金色。
- 配色不宜超过两种主色；局部黑点、细线或色标可以充当小面积强调。
- 渐变只能是纸面受光造成的细微明暗，不能成为装饰主角。

## 缩略图门槛

将画面缩小后，仍应在三秒内识别：一个视觉重心、一个纸面动作、一个安静释放区。若视觉重心、标题和辅助元素都同等抢眼，先删减而不是继续添加装饰。

## 必须避免

- 厚重挤出字、橡胶/塑料发泡、镜面金属、宝石、石膏浮雕、深黑投影。
- 多个象征物、复杂插画、花哨背景、图案填满留白、常规 PPT 式对齐。
- 频繁使用正中标题 + 居中图标的模板；除非用户明确要这一种结构。
