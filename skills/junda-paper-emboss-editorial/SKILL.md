# Junda Paper Emboss Editorial

把一个主题与少量信息转成有纸张触感的编辑视觉：无涂层纸、浅击凸/压凹、克制留白、文字与图形的关系，以及一个清晰的视觉隐喻。它不是给平面图叠加 3D 滤镜，也不是复刻参考海报。

## 适用边界

- 用于文章封面、社交媒体封面、品牌主题图、书封概念图、活动海报和无字网站 Hero。
- 默认单张 `3:4` 竖幅；尊重用户指定的比例与用途。
- 不用于人物或产品保真转绘、写实棚拍、金属蚀刻、厚重 3D 标识、密集信息图或复杂叙事插画。
- 不复制外部作品的主题、文字、签名、水印、Logo、可识别构图或完整提示词；只使用通用的纸材、工艺和编辑设计规律。

## 输入与默认值

从用户请求直接提取下列信息；不为可以安全默认的字段停下来追问。

| 字段 | 作用 | 缺省处理 |
| --- | --- | --- |
| 主题 | 决定情绪与主隐喻 | 从标题推断 |
| 标题 | 主要信息 | 将主题缩成 2–8 个字或简短词组 |
| 副标题/短句 | 第二层信息 | 留空，不虚构文案 |
| 比例与用途 | 决定版式/安全区 | `3:4`、社交封面 |
| 语言 | 决定文字处理 | 跟随用户原文 |
| 颜色、品牌限制、禁用元素 | 约束视觉系统 | 选纸基 + 1–2 个主色 |
| 模板键、固定版式或多版本要求 | 选择可复用构图 | 未指定时按主题自由选一个版式家族 |
| 参考图、权属与保留/改变意图 | 决定参考图分支与可传入的特征 | 无说明时按 `style-only + analyze-only`；自有/获授权图记录用户想保留和改变的内容 |

品牌名、法律文案、数据、日期，以及文章头图、书封、公众号封面的用户原文，默认进入“严格文字模式”。只有用户明确接受近似文字时，才让图像模型直接排字。

## 参考图生成

参考图可以参与生成新的独立设计，但必须先读取 [参考图工作流](references/reference-image-workflow.md)，建立 `reference_contract`。用户可在调用时直接附上一张参考图，并说明“想保留什么 / 想改成什么”；这两项意图只能在契约允许的范围内执行，不能把“保留”理解为复刻来源内容。

- **style-only**：提炼纸材、压纹深度、侧光、色温和信息密度。外部或权属未知图片只允许 `analyze-only`；仅对用户自有或明确获授权、无人物/产品/地标、无来源文字/Logo/签名/水印的单张风格图，允许 `direct-conditioned` 作为生成器参考。用户可以要求保留上述可迁移的纸面规律，并要求改换主题、隐喻、版式、标题角色、配色或比例。
- **composition-only**：只提炼至多两个粗粒度布局原则，例如主视觉区、留白区或阅读方向。永远先抽象为文字/3×3 布局规则，不能把原图直接传给生成器。
- **subject-photo**：本 Skill 不做人物、宠物、产品包装或地标的保真转译。需要保留主体身份时，应使用专门的参考图转译流程，而不是把它伪装成风格参考。

如果用户要求保留来源文字、Logo、水印、精确版式，或人物/产品外观，这些要求不进入 `direct-conditioned`；只可提取仍然合规的非识别性规律，或转交主体保真流程。用户给出图片、链接或截图却没有说明角色时，交付中必须说明“按 `style-only + analyze-only` 处理”。每张成图最多使用一张 `direct-conditioned` 风格图；多图候选没有明确主图时全部保持 `analyze-only`，不得把整篇文章或整组作品直接作为图像输入。

## 生成流程

1. 解析主题、用途、文字精度、参考图契约，以及用户明确的保留/改变意图。
2. 写一句内部设计判断：主题真正的情绪、关系、动作或状态是什么。
3. 选择 **一个** 主视觉隐喻；可以是压痕、路径、门、波纹、台阶、天体、纸缝或极简物件，不能堆叠多个象征。
4. 用户指定模板键、请求可复用版式或多版本，或其用途和比例明确命中模板库的适用场景时，读取 [模板库](references/template-library.md)，优先选最匹配的模板；用户明确要求一次性自由创作时才跳过。每个版本只选一个模板；除非用户明确要求混合，否则不混合模板结构。
5. 读取 [设计系统](references/design-system.md)，选择一个版式家族、一个工艺主次关系和一个纸基/色彩关系。
6. 多版本任务为每版记录离散的“版式、隐喻、标题位置、工艺、配色”五项设计指纹；新版本至少替换两项，细微位置或色差不计为变化。
7. 读取 [提示词蓝图](references/prompt-blueprint.md)，把设计、参考图契约和允许的保留/改变意图整合成一份完整规格，而不是机械拼接风格词。
8. 用户需要图片且图像生成工具可用时，按契约传入参考图或只传文字规格，生成后逐项检查。只需要提示词时，交付完整规格与设计指纹。
9. 若关键工艺、原创性或版式条件不成立，只做一次针对性修正；不要盲目重复同一提示词。

## 工艺与内容预算

- 纸面必须是无涂层、可见细纤维或轻微压纹的纸；击凸/压凹只呈现浅层触感。
- 使用同一方向约 35–55 度的柔和侧光、克制边缘高光和极浅阴影；同色或近同色工艺关系优先。
- 一张图只保留一个主隐喻，最多加 1–2 个微小编辑辅助元素。
- 信息最多三级：主标题、可选副标题、少量微型索引。主标题必须参与构图而不是贴在画面上。
- 颜色是“纸基 + 1–2 个有明确职责的主色”；允许极小强调色，留白本身是构图元素。

## 严格文字模式

文字必须逐字准确时，读取 [严格文字模式](references/strict-text-mode.md)。图像模型负责纸材、压痕、光线和无字构图；精确文案必须使用真实可编辑文字层。默认 `3:4` 和 `16:9` 都有对应 SVG 文字层模板。不能把近似文字说成排版成品。

## 完成前检查

- 纸材可感知，不是塑料、石膏、金属、厚纸板或软 3D 渲染。
- 至少一组元素呈现浅击凸或压凹：有压痕边缘，且高光/阴影受同一光向约束。
- 有且只有一个主视觉隐喻；没有复杂背景、无关插画或装饰堆砌。
- 标题、辅助信息、微型索引与留白形成明确关系；缩略图下仍能读出视觉重心。
- 配色、纸材、光线和工艺一致；没有复杂渐变、镜面金属感、塑料感或厚重投影。
- 若任何主视觉、标题或阴影像脱离纸面的独立雕塑、悬浮物或厚纸板，判失败；下一轮只降低浮雕深度与阴影强度。
- 参考图输出通过 [参考图工作流](references/reference-image-workflow.md) 的原创性和泄漏检查。
- 若有参考图，用户要求保留/改变的可迁移特征已被执行；任何不允许的来源内容仍未进入成图或承诺范围。
- 若使用模板库，所选模板的验收点全部成立，且没有混入第二个模板的结构或隐喻。
- 精确文字交付必须说明是否已包含可编辑覆盖层；没有覆盖层时只能称“无字艺术底图”。

## 交付

简短说明主隐喻、版式/工艺主次、模板键（如有）、参考图模式与文字模式，并提供成图或完整提示词。多版本交付列出每版五项离散设计指纹以及至少两项实质变化。项目内图片只能保存当前运行明确返回的文件，不能从通用生成目录猜测或伪造。
