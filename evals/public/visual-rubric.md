# Visual review rubric

| 维度 | 不通过 | 通过 |
| --- | --- | --- |
| 纸材 | 平滑数字底色、塑料、石膏或金属表面 | 无涂层纸面有细纤维/压纹，材料感统一 |
| 工艺 | 厚重挤出、悬浮阴影或不一致光向 | 浅击凸/压凹有真实压痕边缘，柔侧光方向一致 |
| 视觉重心 | 多个符号和装饰彼此竞争 | 一个主隐喻，缩略图可迅速识别，留白形成释放区 |
| 编辑秩序 | 居中模板、密集微文案或普通图文拼贴 | 标题、图形、边缘和留白有主动关系，信息最多三级 |
| 色彩 | 多色、炫光、复杂渐变或无职责点缀 | 纸基 + 1–2 个有明确职责的主色，明暗来自材料受光 |
| 文字 | 伪文字、错字被当作成品 | 严格文字模式有无字底图与可编辑文字层；近似模式明示限制 |
| 参考图 | 源图文字、Logo、主体或可识别构图泄漏；忽略已声明的合规保留/改变意图 | 只保留契约允许且用户指定的规律，落实新的设计意图，成图是独立设计 |
